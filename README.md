# 생활·사업 도구모음 사이트

참고 사이트 `https://datecalc.topicnow.kr/ko/#everyday`의 핵심 구조(도구 목록 → 즉시 사용 → 결과와 설명)를 참고해 만든 독립적인 사이트입니다. 디자인과 문구는 새로 작성했습니다.

공개 주소: `https://rushnam79-cmyk.github.io/hanune-tools/` (GitHub Pages 활성화 후 접속 가능)

## 현재 들어 있는 기능

- 브라우저에서 바로 쓰는 날짜 차이, D-day, 부가세 계산기
- 기존 Windows 프로그램 6종의 기능·사용 환경 안내와 클릭 가능한 상세 설명
- 모바일 화면 대응, 도구 검색, 접근 가능한 입력 레이블
- 입력값은 브라우저에서만 계산하며 서버로 보내지 않음

## 실행

`index.html`을 더블클릭하면 기본 브라우저에서 열립니다. 공개 페이지는 GitHub Pages에서 제공합니다. PC 프로그램의 구매 버튼은 공개 상품 주소가 확인된 제품만 연결합니다.

## 제품 운영 원칙

기존 제품의 소스·판매 ZIP·발급키는 이 폴더에 복사하지 않습니다. 사이트의 계산기는 무료 체험용 도구이고, Windows 프로그램은 각 제품 폴더에서 별도로 관리합니다. 판매 링크는 실제 승인된 상품 주소를 확인한 뒤 연결합니다. 브라우저용 전체 제품 전환은 기능별 재구현과 별도 검증이 필요합니다.

PC 프로그램은 카드의 `자세히 보기`로 용도를 확인하고, 판매가 공개된 제품만 `크몽에서 구매하기` 버튼을 보여줍니다. 구매자는 결제 후 크몽 주문을 통해 해당 제품의 고객용 파일과 사용설명서, 필요한 경우 인증키를 받아 Windows PC에서 실행합니다. 현재 공개 구매 주소가 검증되지 않아 6개 제품 모두 구매 링크가 비활성화되어 있습니다. 판매자용 크몽 편집 주소를 구매자에게 연결하지 마세요.
